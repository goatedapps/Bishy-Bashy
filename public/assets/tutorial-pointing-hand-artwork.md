# Totem tutorial pointing hand

Created with the built-in imagegen tool for Totem Shrinker's looping How to play demonstration.
The retained master is `tutorial-pointing-hand.png`; the optimized 256-pixel WebP is registered by `scripts/optimize-images.py` and preloaded through the asset manifest.
The demo reuses the existing Totem block sprite sheet and temple background.

## Prompt

Use case: illustration-story.
Asset type: small pointing-hand sprite for an existing colorful cartoon party game's How to play animation.
Generate one isolated friendly cartoon right hand with warm light peach skin, viewed from the back, index finger extended straight UP with its fingertip at the top center, remaining fingers curled naturally, small thumb to the left and a little wrist at bottom.
Thick clean dark-purple outline, soft simple warm shading, polished playful 2D game illustration.
Single hand centered, fully visible, tightly framed with only a small transparent margin.
Genuine transparent background, no button, no touch ripple, no text, no scenery, no extra hands.
The tip of the extended index finger will touch a UI button above the hand.
